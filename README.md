# Lightspeed

A true-scale 3D model of the Solar System that you can fly through at (and past) the speed of
light. It runs in the browser and explains the physics along the way.

> Work in progress. The full README, with credits and physics notes, comes with the final milestone.

## Run it

```bash
npm install
npm run dev
```

```bash
npm test        # physics unit tests (vitest)
npm run build   # static build to dist/
```
